# Orvanta app family

Approved name: **Orvanta**. This is the umbrella brand, followed by each app's purpose. The current product is **Orvanta Video Downloader**.

Orvanta is a coined name without an established dictionary meaning. No trademark or domain availability claim is made.

## Product identity

- Display name: Orvanta Video Downloader.
- Artifact prefix: OrvantaVideoDownloader.
- Developer: Ahmed Eladwy, eladwy.ahmed@gmail.com.
- The existing text-free download/play icon is retained for this product.
- The compact main window remains free of a redundant brand heading. Branding appears in the window title, tray, About, setup and executable metadata.

## Compatibility

The Qt application/organization identifiers and single-instance IPC name remain stable for compatibility with previous releases. These internal strings are not the public product name. They preserve the AppData settings, queue, history, browser pairing and activation channel.

New installations use an Orvanta folder and uninstall entry. Setup refuses a destination containing the earlier branded executable; the old installation and its uninstaller are preserved. The repository URL is unchanged.

The first Orvanta release is 1.0.1 for Windows x64. Earlier reports and v1.0.0 release notes retain their historical names.
