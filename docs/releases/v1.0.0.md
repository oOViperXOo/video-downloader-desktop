# Orvanta Video Downloader 1.0.0

Developed by Ahmed Eladwy, Orvanta.

- Compact Windows interface with active and completed downloads in one table.
- Parallel downloads, pause/resume, and single or multiple connections.
- Playlist folders and automatic filename prefixes configured in Settings > Playlists.
- Per-item quality controls, original media formats, and optional MP4/MP3 copies.
- Row selection, keyboard deletion, file actions, and safe double-click opening.
- Browser login integration, optional browser companion extension, tray minimization, and single-instance operation.

## Downloads

- **Portable.exe**: recommended standalone EXE. Settings and history use the Windows user's AppData.
- **Setup.exe**: choose Portable (default) or installation for the current Windows user.
- **Source.zip**: source snapshot, without bundled runtimes or local user state.
- **SHA256SUMS.txt**: checksums for the three downloads.

Windows x64. Portable and installed builds include their runtime dependencies. The executables are currently unsigned.
