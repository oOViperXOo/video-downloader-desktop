# Orvanta Video Downloader 1.0.1

Orvanta is the umbrella brand for this app family. Developed by Ahmed Eladwy, eladwy.ahmed@gmail.com.

- New Orvanta name throughout the app, tray, About dialog, Windows executable metadata, setup and browser companion.
- Portable and Setup files now use the OrvantaVideoDownloader name.
- Existing settings, queue, history and browser pairing continue to use the compatible AppData location. No manual migration is needed.
- Single-instance protection also works with older releases. Fully exit the previous app, including the tray, before launching this update.
- The installer uses an Orvanta folder and Windows uninstall entry. An earlier installed version is preserved; uninstall it separately when no longer needed. Use a separate destination for the new version.
- The existing text-free download/play icon and Ahmed Eladwy's developer credit are retained.

## Downloads

- **OrvantaVideoDownloader-Portable.exe**: recommended standalone Windows x64 EXE.
- **OrvantaVideoDownloader-Setup.exe**: Portable (default) or installation for the current Windows user.
- **OrvantaVideoDownloader-Source.zip**: source snapshot without runtimes or local user state.
- **SHA256SUMS.txt**: checksums for these three files.

Windows x64 only. The executables remain unsigned. No Linux or macOS packages are included.

Validation: 330 application tests passed, 4 skipped; all 17 browser-companion tests passed. Native Windows startup confirms the new product name and unchanged AppData location.

Both packaged builds passed GUI/source checks and Windows product/version metadata checks. Setup verification matched all 1351 installed payload files, preserved user files on uninstall, and confirmed that Portable extracts only one EXE. Both setup modes refused a folder containing the earlier branded executable without changing its files or registration.
