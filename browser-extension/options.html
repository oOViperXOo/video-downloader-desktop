Orvanta Video Downloader Companion

1. Pair with the app

In the desktop app, open "Pair browser" and copy the code (valid 2 minutes).

App port: Default 17653. Must match the app.

2. Detect media automatically (optional)

Needs permission to observe network responses on all websites. Only the media link, its type and size are kept in memory for the open tab; nothing leaves this computer except what you press "Send" on.

3. Cookies (optional)

Needed for videos that require you to be logged in. Cookies go only to the app on this computer (127.0.0.1) and are not stored by the extension. Off by default.
